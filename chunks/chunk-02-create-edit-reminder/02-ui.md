# UI Specification — Chunk 02: Create & Edit Reminder Flow

## 1. Create Reminder Wizard Screens (`CreateReminderScreen`)
- **Step 1: Select Template**
  - Displays list of template cards (Title, Context name + Icon, Item count).
  - "Skip / Scratch" button at top/bottom.
- **Step 2: Context Selection**
  - OutlinedTextField for Context Title.
  - Grid/List selector for Material Vector Icons (`ContextIcons.AVAILABLE_ICONS`).
- **Step 3: Checklist Manager**
  - TextField + "Add Item" button for new items.
  - LazyColumn of checklist items: editable text, Move Up/Down buttons, Delete button.
- **Step 4: Departure & Notification Settings**
  - Date Picker & Time Picker for Departure Time.
  - FilterChip or Radio button group for Lead Times: 15m, 30m (default), 45m, 1h, Custom.
  - Custom lead time TextField when Custom is selected.
  - Validation error text if selected departure time is in the past.
- **Step 5: Reminder Preview**
  - Summary card displaying Context, Icon, Departure Date & Time, Notification Time, and Checklist Items.
  - Quick edit buttons for steps.
  - Checkbox: "Save as new template?".
  - Primary button: "Create Reminder".
  - Secondary button: "Cancel" (triggers Discard Confirmation Dialog).

## 2. Edit Reminder Screen (`EditReminderScreen`)
- Single scrolling form displaying Context, Checklist items (add/edit/delete/reorder), Departure Date & Time pickers, Notification Lead Time selector.
- TopAppBar with back arrow and "Edit Reminder" title.
- "Save Changes" primary button.
- Cancel button triggering Discard Confirmation Dialog if modified.
