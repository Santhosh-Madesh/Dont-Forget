# UI Specification — Onboarding Feature (`onboarding-chunk`)

## 1. Overview
Stateless Jetpack Compose UI architecture for the 7 onboarding screens matching `@onboarding-screen1.png` through `@onboarding-screen7.png`.

## 2. Stateless Composable Components

### 2.1 `OnboardingScreen` (Container Composable)
Main host rendering the active screen step based on `state.currentStep`:
- Parameter: `state: OnboardingUiState`
- Parameter: `onEvent: (OnboardingUiEvent) -> Unit`
- Parameter: `onScheduleTestAlarm: (title: String, content: String) -> Unit`

### 2.2 Screen Composables
1. **`OnboardingWelcomeStep` (Screen 1)**:
   - Renders top illustration badge (checklist card with lock/check inside light green circle).
   - Renders headline: "Never forget a thing before leaving."
   - Renders body text: "Create a checklist for where you're going and get reminded before you leave."
   - Renders primary CTA button: `Get Started` -> emits `OnboardingUiEvent.OnGetStartedClicked`.
   - Renders secondary text button: `Skip` -> emits `OnboardingUiEvent.OnSkipClicked`.
2. **`OnboardingChooseContextStep` (Screen 2)**:
   - Header: `<- New Reminder` + Step indicator `STEP 1 OF 5`.
   - Title: "Where are you going?" + Subtitle: "Choose a context for the things you need to remember."
   - Input field: Label "Destination or Place", location pin icon, text input `state.contextText`, helper text "e.g., Gym, Work desk, Flight gate".
   - Primary CTA: `Next ->` -> emits `OnboardingUiEvent.OnNextClicked`.
3. **`OnboardingAddItemsStep` (Screen 3)**:
   - Header: `<- New Reminder` + Step indicator `STEP 2 OF 5`.
   - Title: "What do you need to take?" + Subtitle: "Add the things you don't want to forget when leaving for ${state.contextText}."
   - Field: "Add an item" text field + `+` button -> emits `OnboardingUiEvent.OnAddItemClicked`.
   - List: `state.checklistItems` rendered as cards with remove `x` button -> emits `OnboardingUiEvent.OnRemoveItemClicked(item)`.
   - Primary CTA: `Next ->` -> emits `OnboardingUiEvent.OnNextClicked`.
4. **`OnboardingConfigureTimingStep` (Screen 4)**:
   - Header: `<- New Reminder` + Step indicator `STEP 3 OF 5`.
   - Title: "When should we remind you?"
   - Time Picker: `state.departureTimeText` with hour/minute selector and AM/PM toggle.
   - Notification Timing Card: "Now" (Test Alert chip selected) + info text.
   - Primary CTA: `Next ->` -> emits `OnboardingUiEvent.OnNextClicked`.
5. **`OnboardingConfirmationSummaryStep` (Screen 5)**:
   - Header: `<- New Reminder` + Step indicator `STEP 4 OF 5`.
   - Icon badge: Green checkmark circle.
   - Title: "Reminder Created!" + Subtitle: "You're all set. We'll remind you before you leave."
   - Card Summary: Context `state.contextText`, Departure `state.departureTimeText`, Reminder `state.reminderLeadText`, Packing checklist preview chips (`state.checklistItems`).
   - Primary CTA: `Done ✓` -> emits `OnboardingUiEvent.OnConfirmReminderClicked`.
6. **`OnboardingInteractivePackingStep` (Screen 6)**:
   - Header: Top alert chip "Live Test Alert Received" + Step indicator `STEP 5 OF 5`.
   - Subtitle chip: `Destination: ${state.contextText}`.
   - Title: "Look at that, your phone buzzed." Subtitle: "Did you actually notice... prove you're ready."
   - Cargo Section: Counter "Your Cargo ${state.packedItems.size} of ${state.checklistItems.size}", `✓ Pack all` button -> emits `OnboardingUiEvent.OnPackAllClicked`.
   - Checkbox items: Toggles items -> emits `OnboardingUiEvent.OnToggleItemPacked(item)`.
   - Primary CTA: "Check off items above" / "Finish setup" -> emits `OnboardingUiEvent.OnNextClicked`.
7. **`OnboardingCompletionVictoryStep` (Screen 7)**:
   - Top Header: Close icon `X` button -> emits `OnboardingUiEvent.OnFinishOnboardingClicked` + Brand pill `• DON'T FORGET V2`.
   - Double-circle checkmark icon, Victory pill: `✓ Active • 4 items packed • Crisis averted`.
   - Title: "Look at you. Fully prepared." Body text celebrating preparedness.
   - Verified Inventory section: Chips (`Keys & FOB`, `Work Badge`, `Noise Canceling`, `Water Bottle`).
   - Primary CTA: `Got it, let's roll ->` -> emits `OnboardingUiEvent.OnFinishOnboardingClicked`.
