# UI Spec — Chunk 05: Notification Display Feature (`chunk-05-notification-display`)

## 1. Notification Screen Layout Structure (`com.example.dontforget.feature.notifications.screen`)

### `NotificationScreen` Composable
- **`Scaffold`**:
  - `TopAppBar`:
    - Title: `"Notifications"` (`titleLarge`, Bold).
    - Navigation Icon: `Icons.AutoMirrored.Filled.ArrowBack` (calls `onNavigateBack`).
- **Body Content (`Box`)**:
  - **Empty State View (`EmptyNotificationContent`)**:
    - Displayed when `state.isEmpty == true`.
    - Centered Column with `NotificationsNone` icon (64.dp), title `"No Notifications"`, and body `"You don't have any upcoming or previous notifications at the moment."`.
  - **Notification History List (`LazyColumn`)**:
    - Displayed when `state.isEmpty == false`.
    - **UPCOMING Section**:
      - Header Row: `"UPCOMING"` (Primary color) + Inline count (e.g. `2`).
      - List items: `NotificationItemRow` displaying Title, relative departure time (e.g., `"Tomorrow · 8:30 AM"`), content subtitle, and subtle list item dividers.
    - **Section Divider**:
      - `HorizontalDivider` rendered between UPCOMING and PREVIOUS sections when both are non-empty.
    - **PREVIOUS Section**:
      - Header Row: `"PREVIOUS"` (OnSurfaceVariant color) + Inline count (e.g. `2`).
      - List items: `NotificationItemRow` displaying Title, relative departure time (e.g., `"Nov 1 · 9:00 AM"`), content subtitle, and subtle list item dividers.
    - **Footer**:
      - Centered text `"DONT FORGET · LOCAL HISTORY"` (`labelSmall`, muted color).

---

## 2. Component Specifications

### `NotificationItemRow` Composable
- **Title**: Context / Reminder title (`titleMedium`, Bold).
- **Timestamp**: Right-aligned relative departure date & time string (`bodySmall`, muted color).
- **Content**: Subtitle text matching notification builder (`bodyMedium`, muted color).
