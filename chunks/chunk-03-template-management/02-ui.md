# UI Spec — Chunk 03: Template Management (`chunk-03-template-management`)

## 1. Template Management Screen Components (`com.example.dontforget.feature.templates.management`)
- **`TemplateManagementScreen`**:
  - `Scaffold` with `AppTopBar` (title "Template Management"), FAB "+ New Template".
  - Content:
    - If `templates.isEmpty()`: `EmptyTemplateContent` ("No Templates Yet" icon, text, and "Create Template" button).
    - Else: `LazyColumn` grouped by Context (`ContextSection` header with icon & title, containing `TemplateCard` list).
- **`TemplateCard`**:
  - `Card` displaying Template Title and item count (e.g. "5 items"). Tapping card navigates to `TemplateDetailScreen(templateId)`.

## 2. Template Detail Screen Components (`com.example.dontforget.feature.templates.detail`)
- **`TemplateDetailScreen`**:
  - `Scaffold` with `AppTopBar` (title "Template Details", back arrow, overflow/action icons for Edit and Delete).
  - Context Header: Context Icon + Context Title + Template Title.
  - Content: Checklist items list (`ChecklistItemRow` displaying bullet/icon + item text).
  - Delete confirmation dialog.

## 3. Template Edit Screen Components (`com.example.dontforget.feature.templates.edit`)
- **`TemplateEditScreen`**:
  - `Scaffold` with `AppTopBar` (title "Create Template" or "Edit Template", back arrow).
  - Form Fields:
    - Context section: Dropdown/picker to select existing Context (from `getAllContexts()`) or toggle to "Create New Context" (Text field for Context Name + Grid of Material Vector Icons from `ContextIcons`).
    - Template Title `OutlinedTextField`.
    - Checklist Items section: Header + "Add Item" `OutlinedTextField` with IconButton (`Add`). List of added items with `IconButton` (`Delete`) to remove items and reorder controls.
  - Bottom bar: "Save Template" `Button`.
