# UI Spec — Chunk 00: Shared Foundation (`chunk-00-foundation`)

## 1. Design Tokens & Theme Setup

### Theme Colors (`Color.kt`, `Theme.kt`)
- **Light Theme**:
  - `primary`: Dark Teal (`Color(0xFF00668A)`)
  - `onPrimary`: White (`Color(0xFFFFFFFF)`)
  - `primaryContainer`: Light Ice Blue (`Color(0xFFC3E8FF)`)
  - `background`: Very Light Grey (`Color(0xFFF8F9FF)`)
  - `surface`: White (`Color(0xFFFFFFFF)`)
  - `surfaceVariant`: Pale Blue Grey (`Color(0xFFE0E2EC)`)
  - `error`: Crimson Red (`Color(0xFFBA1A1A)`)
- **Dark Theme**:
  - `primary`: Bright Ice Blue (`Color(0xFF76D1FF)`)
  - `onPrimary`: Dark Teal (`Color(0xFF003548)`)
  - `primaryContainer`: Deep Teal (`Color(0xFF004C68)`)
  - `background`: Dark Slate Grey (`Color(0xFF191C1E)`)
  - `surface`: Dark Slate Surface (`Color(0xFF191C1E)`)
  - `surfaceVariant`: Dark Slate Variant (`Color(0xFF43474E)`)
  - `error`: Soft Red (`Color(0xFFFFB4AB)`)

### Typography (`Type.kt`)
- Material 3 Typography utilizing system default font family with appropriate scale for Title Large, Title Medium, Body Large, Body Medium, Label Large.

## 2. Shared Common UI Components

### `AppTopBar`
- Material 3 `CenterAlignedTopAppBar` or `TopAppBar`.
- Displays title, optional navigation back icon (`ArrowBack`), and optional trailing action icons.

### `WarningBanner`
- Banner component displayed at the top of screens when notification permission is missing.
- Contains warning icon, message ("Notification permissions required to receive reminders"), and a CTA button ("Enable in Settings") as shown in `UI References/Create Reminder - Select departure and notification warning dialog Screen.png`.

### `ConfirmationDialog`
- Reusable M3 `AlertDialog`.
- Props: `title`, `message`, `confirmText`, `dismissText`, `onConfirm`, `onDismiss`.
- Used for Delete Confirmation, Discard Confirmation, etc.
