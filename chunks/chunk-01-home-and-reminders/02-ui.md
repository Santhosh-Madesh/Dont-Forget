# UI Spec — Chunk 01: Reminders & Home Screen (`chunk-01-home-and-reminders`)

## 1. Home Screen Components (`com.example.dontforget.feature.home.ui`)
- **`HomeScreen`**:
  - `Scaffold` with `AppTopBar` (title "DONT FORGET", action icon for Templates), FAB ("+ New Reminder" with `Add` icon).
  - Content:
    - If `activeReminders.isEmpty()`: `EmptyHomeContent` with illustration/icon, "No Reminders Yet" text, and "Create Reminder" button.
    - Else: `LazyColumn` of `ReminderCard` items.
- **`ReminderCard`**:
  - `Card` (Outlined or Filled) with padding.
  - Row 1: Context Icon + Context Title + Overflow Menu / Action.
  - Row 2: Departure Date & Time (e.g., "Leaving at 05:00 PM, Today").
  - Row 3: Packed badge / progress indicator (e.g. "3/5 Packed").

## 2. Reminder Detail Screen Components (`com.example.dontforget.feature.reminderdetail.ui`)
- **`ReminderDetailScreen`**:
  - `Scaffold` with `AppTopBar` (title "Reminder Overview", back arrow, overflow menu for Edit / Delete).
  - Header: Context Icon + Context Title, Departure Date & Time, Notification Lead Time info ("Reminder 30 mins before").
  - Content:
    - "Checklist" section header + "Pack All" text button.
    - `LazyColumn` of checklist items with `Checkbox` + item text (strikethrough when packed).
  - Bottom bar / Action section:
    - "Update" button to save packing state.
    - If 100% items packed: "Mark as Complete" popup card / button.
    - If reminder is completed: "Restore Reminder" banner/card asking to uncheck at least 1 item.
- **Dialogs**:
  - `DeleteReminderDialog`: Confirmation dialog for deleting reminder.
  - `MarkCompleteCard`: Popup card confirming completion.
