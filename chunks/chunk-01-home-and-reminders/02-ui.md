# UI Spec — Chunk 01: Home Feature (`chunk-01-home-and-reminders`)

## 1. Home Screen Layout Structure (`com.example.dontforget.feature.home`)

### `HomeScreen` Composable
- **`Scaffold`**:
  - `TopAppBar`:
    - Title: `"DONT FORGET"` (`titleLarge`, Bold).
    - Actions: Mock notification icon button (`Icons.Filled.Notifications`).
  - `FloatingActionButton`:
    - Icon: `Icons.Filled.Add`
    - Content Description: `"New Reminder"`
- **Body Content (`LazyColumn` / `Column`)**:
  1. **Date & Title Section Header**:
     - Text 1: Today's Date formatted (e.g., `"Thursday, Oct 15"` in `titleMedium`, onSurfaceVariant color).
     - Text 2: Section Title `"Reminders"` (`headlineMedium`, Bold).
  2. **Notification Permission Warning Card (`WarningBanner`)**:
     - Conditionally displayed **ONLY if `!isNotificationPermissionGranted`**.
     - Completely hidden from layout when permissions are granted (`true`).
     - **Coloring**: Styled in **yellow warning color** (Material Amber / Yellow container, e.g. `Color(0xFFFFF3CD)` / `Color(0xFFFFECB3)` with dark amber text `Color(0xFF856404)`).
     - Contains warning message and CTA button `"Enable in Settings"`.
     - **Layout Sizing**: Hugs its internal content and container width with snug padding (`fillMaxWidth`, `wrapContentHeight`).
  3. **Active / Completed Segmented Filter Toggle Component**:
     - **Outer Parent Container**: `Surface` / `Box` with a **large rounded border radius** (e.g., `RoundedCornerShape(24.dp)` or `CircleShape` pill container) and background container color (`surfaceVariant`).
     - **Inner Segment Buttons ("Active" & "Completed")**:
       - Each button has equal width (`Modifier.weight(1f)`).
       - Each button has its own **rounded border radius** (`RoundedCornerShape(20.dp)` or `CircleShape`) matching the parent's curvature.
       - **Center Alignment**: Button text ("Active" / "Completed") is strictly **center-aligned** (`TextAlign.Center` / `Alignment.Center`).
       - **Active State**: Primary container background with bold, high-contrast text.
       - **Inactive State**: Transparent background with muted on-surface-variant text.
  4. **Categorized Reminders List (When Active Selected)**:
     - **Section Headers**:
       - **"TODAY" Section Header** (`titleSmall`, Bold, Primary color)
       - **"TOMORROW" Section Header** (`titleSmall`, Bold, Primary color)
       - **"UPCOMING" Section Header** (`titleSmall`, Bold, Primary color)
     - Each category lists corresponding `ReminderCard` composables.
     - If no active reminders exist across all categories: Renders `EmptyHomeContent`.
  5. **Completed Reminders List (When Completed Selected)**:
     - Displays list of completed `ReminderCard` items.
     - If no completed reminders exist: Renders `EmptyHomeContent` with title `"No Completed Reminders"`.

---

## 2. Component Specifications

### `ReminderCard` Composable
- **Container**: `Card` (Filled / SurfaceVariant) with rounded corners and padding.
- **Header Row**:
  - `Surface` container with Context Icon (`ContextIcons.getIconByName(...)`).
  - Context Title (`titleMedium`, Bold).
  - Departure Date & Time string (e.g., `"Leaving at 05:00 PM"`).
- **Tags & Badges Row**:
  - **Notification Lead Time Tag**:
    - Bell icon (`Icons.Filled.Notifications`) + lead time text (e.g., `"30 min before"`).
  - **Packing Status Tag**:
    - `"Fully packed"` (green/primary badge when 100% of items are packed).
    - `"Not started"` (gray/container badge when 0% of items are packed).
    - `"X/Y Packed"` (secondary badge for partial packing progress).
  - **Urgency Tag**:
    - Displayed **ONLY if departure time is within 1 hour** (`<= 60 minutes` from current time).
    - Format: `"Leaves in X min"` (e.g., `"Leaves in 45 min"`) with error/warning container background.

### `EmptyHomeContent` Composable
- Displays empty illustration bell icon (`Icons.Filled.NotificationsActive`), contextual title (e.g., `"No Active Reminders"` or `"No Completed Reminders"`), description body, and CTA button `"Create Reminder"`.
