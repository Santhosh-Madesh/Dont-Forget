# UI Spec — Chunk 01: Home Feature (`chunk-01-home-and-reminders`)

## 1. Home Screen Layout Structure (`com.example.dontforget.feature.home`)

### `HomeScreen` Composable
- **`Scaffold`**:
  - `TopAppBar`:
    - Title: `"DONT FORGET"` (`titleLarge`, Bold).
    - Actions: Mock notification icon button (`Icons.Filled.Notifications`).
  - `FloatingActionButton`:
    - Icon: `Icons.Filled.Add`
    - Label: `"New Reminder"`
- **Body Content (`LazyColumn` / `Column`)**:
  1. **Date & Title Section Header**:
     - Text 1: Today's Date formatted (e.g., `"Thursday, Oct 15"` in `bodyMedium` / `titleMedium`).
     - Text 2: Section Title `"Reminders"` (`headlineMedium` / `titleLarge`, Bold).
  2. **Notification Permission Warning Card (`WarningBanner`)**:
     - Conditionally displayed **ONLY if `!isNotificationPermissionGranted`**.
     - Completely hidden when permissions are granted.
     - Contains warning message and CTA button `"Enable in Settings"`.
     - **Layout Sizing**: Hugs its internal content and container width with proper padding (`wrapContentHeight`, `fillMaxWidth` / snug margin).
  3. **Active / Completed Filter Toggle**:
     - Toggle switch/card buttons allowing switching between `"Active"` and `"Completed"` views.
     - **Layout Sizing**: Hugs its container with compact, snug padding.
  4. **Categorized Reminders List (When Active Selected)**:
     - Categories:
       - **"Today" Section Header**
       - **"Tomorrow" Section Header**
       - **"Upcoming" Section Header**
     - Each category lists corresponding `ReminderCard` composables.
     - If no active reminders exist across all categories: Renders `EmptyHomeContent`.
  5. **Completed Reminders List (When Completed Selected)**:
     - Displays list of completed `ReminderCard` items.
     - If no completed reminders exist: Renders `EmptyHomeContent` for completed items.

---

## 2. Component Specifications

### `ReminderCard` Composable
- **Container**: `Card` (Filled/SurfaceVariant) with rounded corners and padding.
- **Header Row**:
  - `Surface` container with Context Icon (`ContextIcons.getIconByName(...)`).
  - Context Title (`titleMedium`, Bold).
  - Departure Date & Time string (e.g., `"Leaving at 05:00 PM"`).
- **Tags & Badges Row**:
  - **Notification Lead Time Tag**: Bell icon (`Icons.Filled.Notifications`) + lead time text (e.g., `"30 min before"`).
  - **Packing Status Tag**:
    - `"Fully packed"` (green/primary badge when 100% of items packed).
    - `"Not started"` (gray/container badge when 0% of items packed).
    - `"X/Y Packed"` (secondary badge for partial packing).
  - **Urgency Tag**:
    - Displayed **ONLY if departure time is within 1 hour** (`<= 60 minutes` from current time).
    - Format: `"Leaves in X min"` (e.g., `"Leaves in 45 min"`) with warning container background.

### `EmptyHomeContent` Composable
- Displays empty illustration bell icon, contextual title (e.g., `"No Active Reminders"` or `"No Completed Reminders"`), description body, and CTA button `"Create Reminder"`.
